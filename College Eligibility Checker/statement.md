# Project Statement: College Eligibility Checker

## Problem

Students often have to look at different eligibility requirements after Class 12. Comparing several sets of marks manually can be confusing, especially when each exam or college category has different conditions.

This project provides a simple command-line program where a student enters their details once and gets a result for several sample eligibility rules.

## Scope

The program asks for:

- Student name
- Number of drop years
- Physics marks
- Chemistry marks
- Mathematics marks
- Biology marks
- Computer marks
- English marks

It checks the entered information and then runs separate eligibility functions for JEE, NEET UG, state government colleges, VITEEE, and BITSAT.

The project is mainly intended for learning Python concepts such as functions, dictionaries, loops, input validation, modules, and conditional statements.

## Target users

- Class 12 students who want to experiment with sample eligibility checks.
- Students learning basic Python programming.
- Teachers or mentors looking for a small example project.

## Main features

- Takes student information through the command line.
- Handles invalid input without stopping the program.
- Keeps the eligibility rules in separate modules.
- Shows all results in one final summary.
- Uses only Python's standard library.

The eligibility values are simplified examples. The program does not connect to official admission systems and should not be treated as a source of official admission information.
